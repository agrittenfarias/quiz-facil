# Quiz Fácil

Repositório contendo jogos e quizzes interativos.

## Como acessar os arquivos

### Formato da URL

Para acessar qualquer arquivo, use o formato:

```
https://agrittenfarias.github.io/quiz-facil/NOME_DO_ARQUIVO.html
```

### Arquivos disponíveis

| Arquivo | Descrição | Link de acesso |
|---------|-----------|----------------|
| `index.html` | Página inicial (redirecionamento) | [Acessar](https://agrittenfarias.github.io/quiz-facil/) |
| `jogos.html` | Jogos interativos | [Acessar](https://agrittenfarias.github.io/quiz-facil/jogos.html) |
| `quiz completo nível facil.html` | Quiz completo nível fácil | [Acessar](https://agrittenfarias.github.io/quiz-facil/quiz%20completo%20n%C3%ADvel%20facil.html) |

### Como acessar

1. Copie um dos links acima
2. Cole no navegador
3. Pronto! O arquivo será carregado automaticamente

### Observação importante

- Os arquivos `.html` são auto-contidos (não precisam de servidor)
- Basta abrir diretamente no navegador
- Funciona em computadores, tablets e celulares
